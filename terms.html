2. Description of Service

Clean Game Turbo is a performance optimization and game utility application for Android devices. The App provides the following features:

  • Game Mode: A manual, per-game overlay feature that displays system performance metrics (CPU, RAM, temperature, battery, FPS) when a gaming session is active. Requires VIP subscription.
  • Game Booster: Performance optimization tools including CPU/RAM management, notification filtering during a game session, and display settings adjustment.
  • Storage & Junk Cleaner: Scans and clears the App's own cache/temporary files, and analyzes storage usage by category (photos, videos, audio) so you can review and free up space.
  • Device Info: Read-only screens showing battery, network, and device information sourced from the Android system.

3. Game Mode Terms

  • Game Mode is a VIP-only feature. It is not available to free tier users.
  • Game Mode is completely manual: it does not automatically activate based on game detection.
  • Game Mode is per-game: each game has independent Game Mode settings that must be enabled individually by the user.
  • Game Mode settings are not retained across app reboots — Game Mode does not resume automatically after device reboot or app restart without explicit user action.
  • When Game Mode is disabled for a game, the overlay will not appear, even if the game is opened.
  • The App overlay is provided as-is and does not measure actual game FPS — it displays the overlay's own frame rate.

4. Storage & Junk Cleaner Terms

  • Deleted cache/junk data cannot be recovered once removed.
