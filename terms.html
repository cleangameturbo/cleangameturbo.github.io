2. Description of Service

Clean Game Turbo is a performance optimization and device-cleaning utility for Android. The App provides the following features:

  • Game Mode: A manual, per-game overlay feature that displays system performance metrics (CPU, RAM, temperature, battery, FPS) when a gaming session is active. Requires VIP subscription.
  • Game Booster: Performance optimization tools including CPU/RAM management, optional notification filtering during a game session, and Do Not Disturb/display settings adjustment for the duration of that session.
  • Cleaner: Scans the App's own cache/temporary files, and lets you review your device's photos, videos, audio, duplicate files, and large files by category — with the option to delete items you select. Deletions of your media go through Android's own system confirmation dialog.
  • App Manager: Lists installed apps that have a launcher entry and lets you open Android's standard uninstall flow for an app of your choice. The App does not uninstall anything without that system-level confirmation.
  • Device Info: Read-only screens showing battery, network, and device information sourced from the Android system.
  • Advertising: Free-tier use of the App displays ads served through Google AdMob. See the Privacy Policy for details on ad consent (EEA/UK) and how to manage it.

3. Game Mode Terms

  • Game Mode is a VIP-only feature. It is not available to free tier users.
  • Game Mode is completely manual: it does not automatically activate based on game detection.
  • Game Mode is per-game: each game has independent Game Mode settings that must be enabled individually by the user.
  • Game Mode settings are not retained across app reboots — Game Mode does not resume automatically after device reboot or app restart without explicit user action.
  • When Game Mode is disabled for a game, the overlay will not appear, even if the game is opened.
  • The App overlay is provided as-is and does not measure actual game FPS — it displays the overlay's own frame rate.
  • The optional "Block Notifications" setting, when enabled for a specific game, suppresses notifications from other apps only while that Game Mode session is active. The App does not read or store the content of any suppressed notification.

4. Cleaner Terms

  • The Cleaner can remove the App's own cache/temporary files, and can also delete photos, videos, audio, and duplicate files that you select yourself from your device's media library.
  • Deleting your media always goes through Android's own system-level delete-confirmation dialog — the App cannot silently delete your media, and cannot access or modify files belonging to other apps.
  • Storage analysis and duplicate detection are performed locally on your device; media files are not uploaded or transmitted anywhere.
  • Deleted files cannot be recovered once removed — review your selection carefully before confirming a deletion.
