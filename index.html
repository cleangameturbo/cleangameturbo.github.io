Privacy Policy — Clean Game Turbo

Terakhir diperbarui: Agustus 2026

Kebijakan Privasi ini menjelaskan bagaimana aplikasi Clean Game Turbo ("Aplikasi") memproses data saat Anda menggunakannya. Aplikasi dikembangkan dan dikelola secara independen. Jika ada pertanyaan, hubungi support.cleangameturbo@gmail.com.

1. Ringkasan

Clean Game Turbo adalah aplikasi utilitas Android untuk membersihkan penyimpanan (cache dan file sampah), mengelola aplikasi terpasang, Game Mode dengan overlay dalam game, Privacy Mode berbasis VPN lokal, dan fitur premium (VIP) melalui langganan Google Play Billing. Aplikasi ini menampilkan iklan (Google AdMob) pada versi gratis.

Aplikasi tidak menggunakan Accessibility Service dan tidak memiliki fitur deteksi aplikasi otomatis ("Auto Mode") dalam bentuk apa pun.

3. Yang TIDAK Dilakukan Aplikasi

  • Tidak menggunakan Accessibility Service untuk membaca layar atau input Anda.
  • Tidak memiliki fitur deteksi/otomatisasi aplikasi tersembunyi ("Auto Mode").
  • Tidak membaca isi paket jaringan yang lewat VPN lokal — hanya dibuang.
  • Tidak menjual data pribadi Anda kepada pihak ketiga.
  • Tidak mengunggah isi file media Anda ke server mana pun.

4. Privacy Mode (VPN)

Privacy Mode menggunakan VpnService bawaan Android untuk membuat tunnel lokal yang, secara default, memblokir akses internet untuk semua aplikasi di perangkat (termasuk game yang sedang Anda mainkan) selagi fitur ini aktif — kecuali Clean Game Turbo sendiri, yang dikecualikan agar notifikasi, verifikasi langganan VIP, dan iklan aplikasi ini tetap berjalan normal. Paket jaringan yang masuk ke tunnel ini hanya dibaca lalu dibuang — tidak pernah diteruskan ke server eksternal mana pun, tidak disimpan, dan tidak dianalisis isinya. Fitur ini sepenuhnya opsional dan hanya aktif setelah Anda menyetujui izin VPN dari sistem Android dan mengaktifkannya sendiri lewat Game Settings atau panel overlay.

5. Iklan (Google AdMob)

Versi gratis Aplikasi menampilkan iklan melalui Google AdMob. Untuk pengguna di EEA, Inggris, dan wilayah yang mewajibkan, Aplikasi menampilkan formulir consent (Google User Messaging Platform/UMP) sebelum meminta iklan, sesuai kerangka kerja IAB TCF/persyaratan Google. Anda dapat meninjau atau mengubah pilihan consent Anda kapan saja lewat menu "Privacy Options" di halaman Pengaturan Aplikasi. AdMob dapat mengumpulkan identifier iklan dan data teknis perangkat sesuai Kebijakan Privasi Google dan Kebijakan Consent Pengguna Google.

6. Pembelian dan Langganan (Google Play Billing)

Fitur VIP (Game Mode, tema premium, bebas iklan) dibeli lewat Google Play Billing dengan paket mingguan atau bulanan. Data pembayaran (kartu, metode pembayaran) diproses sepenuhnya oleh Google Play dan tidak pernah diakses atau disimpan oleh Aplikasi ini. Aplikasi hanya menerima status kepemilikan langganan dari Google Play untuk membuka fitur VIP.

7. Penyimpanan Data

Pengaturan Aplikasi (preferensi tema, status VIP cache, game yang Anda tambahkan, dll.) disimpan secara lokal di perangkat Anda. Aplikasi tidak mengoperasikan server backend sendiri, sehingga data ini tidak disimpan di server milik pengembang.

8. Izin yang Dapat Dicabut

Semua izin di atas dapat dicabut kapan saja melalui Pengaturan sistem Android (Settings → Apps → Clean Game Turbo → Permissions). Mencabut izin tertentu dapat menonaktifkan fitur terkait, tetapi tidak menghapus data yang sudah tersimpan secara lokal di perangkat Anda.

9. Anak-Anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah usia yang disyaratkan hukum yang berlaku, dan tidak dengan sengaja mengumpulkan data pribadi dari anak-anak.

10. Perubahan Kebijakan

Kebijakan Privasi ini dapat diperbarui dari waktu ke waktu. Perubahan material akan tercermin melalui pembaruan tanggal di bagian atas halaman ini dan/atau pembaruan Aplikasi.
